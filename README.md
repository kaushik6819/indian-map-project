
# India Map Game – Python Turtle Project

An interactive **India States Guessing Game** built using **Python Turtle and Pandas**.

This project helps users learn and memorize the **states of India** by guessing their names on a map. When a correct state name is entered, it appears in the correct location on the India map.

## 🎯 Features

✔ Interactive India Map  
✔ Guess the States of India  
✔ Correct answers appear on map  
✔ Score tracking  
✔ Saves missed states automatically  

---

## 🎮 How to Play

1. Run the program
2. India map will appear
3. Enter the name of a state
4. Correct answers will appear on the map
5. Type **End** to quit the game

After quitting the game:

A file named: states_to_learn.csv
will be created containing the states you missed.
